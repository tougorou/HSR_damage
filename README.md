# HSR Damage Calculator

自分専用の崩壊：スターレイル ダメージ計算サイトの土台。

## ファイル
- index.html: UI
- style.css: デザイン
- app.js: UI制御・計算
- data.js: キャラクター、光円錐、攻撃などのマスターデータ

## 方針
asagi-game.com のような「入力→詳細なダメージ結果」という使い勝手を参考にしつつ、コードや固有素材をコピーせず独自実装します。

## 次段階
キャラクター固有効果、光円錐効果、遺物、オーナメント、星魂、軌跡、パーティ4人、敵状態、多段攻撃、追加/付加ダメージ、撃破/超撃破、持続ダメージ、実戦シミュレーションをデータ駆動で追加します。
